# Five-minute demonstration

Prepare the local services and seed accounts using the root README. Use synthetic information. For a reliable presentation, run any live research before recording and reopen its saved guide; model latency and web coverage vary.

| Time | Show | Point to explain |
| --- | --- | --- |
| 0:00–0:30 | One learner problem: scattered learning, unclear next steps | WetinNext connects resources to action and evidence |
| 0:30–1:15 | Sign in as Ada; open Today, then check-in | The plan fits a learner profile and turns study into recorded work |
| 1:15–2:15 | Open a pre-researched non-computing goal, such as introductory nursing | Discovery goes beyond a static catalogue; show exact learning links, local training and qualification limits |
| 2:15–2:45 | Switch between saved goals and open Progress | Work persists independently; the heatmap shows recorded signals, not claimed mastery |
| 2:45–3:30 | Start a short practice quiz; choose count, difficulty and time | Show selected/correct answers and the referenced lesson after submission |
| 3:30–4:00 | CV review with `docs/examples/sample-cv.txt` and preparation actions | Career planning uses evidence and honest gaps |
| 4:00–4:30 | Sign in as Admin; inspect sources/freshness and publication state | Data quality has an operational workflow and role boundary |
| 4:30–5:00 | Show the architecture diagram and verification commands | Explain country expansion and what is deliberately still a prototype |

## Presentation checklist

- Use a saved guide when demonstrating the UI; show a live search only if time/connectivity permit.
- Label seeded activity, AI illustrations and synthetic opportunities clearly.
- Do not call a four-week sprint a nursing qualification, or a quiz score proof of employability.
- If no sourced opening exists, explain the gap instead of presenting an expired or unrelated listing.
- Keep credentials and personal learner data out of recordings.
- End with the learner's next action, then explain the next development milestone.

The web app and these documents support the demo. A final video, slide deck and actual submission upload are not created by this repository cleanup.
